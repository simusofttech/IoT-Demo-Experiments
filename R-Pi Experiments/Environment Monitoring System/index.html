Aim

To build an Environment Monitoring System using Raspberry Pi 4B that measures temperature and humidity using a DHT11 sensor, detects gas using a digital-output gas sensor module, and automatically stores readings in a CSV file.

About the Experiment

The Raspberry Pi continuously reads ambient temperature and humidity from a DHT11 sensor and checks the digital output of a gas sensor module.

The current temperature, humidity and gas status are shown in the terminal and are automatically logged with date and time into a CSV file.

Components Required

Raspberry Pi 4B (×1)

Main controller for sensing, processing and data logging.

DHT11 3-Pin Module (×1)

Measures ambient temperature and relative humidity.

MQ-Series Gas Sensor (×1)

Provides threshold-based gas detection.

10 kΩ Resistors (×3)

Used in the gas sensor voltage divider.

5V Raspberry Pi Power Supply (×1)

Provides power to the Raspberry Pi.

Breadboard (×1)

Used for assembling the circuit.

Used for electrical connections.

Working Principle

Raspberry Pi Starts
↓
DHT11 reads temperature and humidity
↓
Gas sensor digital output is read from GPIO17
↓
Gas state is interpreted as NORMAL AIR or GAS DETECTED
↓
Date and time are captured
↓
Values are displayed in the terminal
↓
Data is stored in environment_data.csv
↓
Process repeats every 2 seconds

Procedure

  1. Connect the DHT11 VCC pin to Raspberry Pi 3.3V.
  2. Connect the DHT11 DATA pin to GPIO4.
  3. Connect the DHT11 GND pin to Raspberry Pi GND.
  4. Connect the gas sensor VCC to 5V.
  5. Connect the gas sensor GND to Raspberry Pi GND.
  6. Connect the gas sensor DO to GPIO17 through the voltage divider.
  7. Power on the Raspberry Pi.
  8. Check all sensor connections.
  9. Activate the Python virtual environment.
  10. Run the environment monitoring Python program.
  11. Allow about 5 seconds for sensor stabilization.
  12. Observe temperature, humidity and gas status in the terminal.
  13. Open the CSV file to view recorded data.
  14. Press Ctrl+C to stop the program safely.

Python Code

environment_monitor.py 
import board
import adafruit_dht
from gpiozero import DigitalInputDevice
from time import sleep
from datetime import datetime
import csv
import os

DHT_PIN = board.D4
GAS_PIN = 17
GAS_DETECTED_STATE = 0

CSV_FILE = "environment_data.csv"

dht = adafruit_dht.DHT11(DHT_PIN, use_pulseio=False)

gas_sensor = DigitalInputDevice(GAS_PIN)

file_exists = os.path.isfile(CSV_FILE)

csv_file = open(
    CSV_FILE,
    mode="a",
    newline="",
    buffering=1
)

csv_writer = csv.writer(csv_file)

if not file_exists:
    csv_writer.writerow([
        "Date",
        "Time",
        "Temperature (C)",
        "Humidity (%)",
        "Gas Status"
    ])

print("RASPBERRY PI ENVIRONMENT MONITOR")

sleep(5)

try:

    while True:

        try:
            temperature = dht.temperature
            humidity = dht.humidity

        except RuntimeError:
            sleep(2)
            continue

        gas_state = gas_sensor.value

        gas_status = (
            "GAS DETECTED"
            if gas_state == GAS_DETECTED_STATE
            else "NORMAL AIR"
        )

        now = datetime.now()

        date = now.strftime("%Y-%m-%d")
        time = now.strftime("%H:%M:%S")

        csv_writer.writerow([
            date,
            time,
            f"{temperature:.1f}",
            f"{humidity:.1f}",
            gas_status
        ])

        print(f"[{date} {time}]")
        print(f"Temperature : {temperature:.1f} °C")
        print(f"Humidity : {humidity:.1f} %")
        print(f"Gas Status : {gas_status}")

        sleep(2)

except KeyboardInterrupt:
    print("Monitoring stopped.")

finally:
    dht.exit()
    gas_sensor.close()
    csv_file.close()

Running the System

Use the desktop shortcut or run the following commands:

source ~/env/bin/activate
python ~/environment_monitor.py
CSV file: /home/pi/environment_data.csv
Sensor stabilization: About 5 seconds
Update interval: Every 2 seconds
Stop program: Ctrl+C

Expected Output

The terminal displays the current date, time, temperature, humidity and gas status. The same data is saved automatically to the CSV file.

Temperature: Displayed in °C
Humidity: Displayed in %
Gas Status: NORMAL AIR or GAS DETECTED
Logging: Automatic CSV recording

Result

The Environment Monitoring System experiment was implemented using Raspberry Pi 4B, a DHT11 sensor and a digital-output gas sensor module. The system monitors environmental conditions and automatically records the readings in a CSV file.
