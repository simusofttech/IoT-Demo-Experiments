Aim

To control a MAX7219CWG 4-module dot matrix display using an ESP32 through a Wi-Fi-based web dashboard.

About the Experiment

The ESP32 hosts a web dashboard over Wi-Fi. The user enters a text message in the dashboard, and the ESP32 sends that message to the MAX7219 dot matrix display.

The message scrolls across the display. The dashboard also provides a button to clear the display.

Components Required

ESP32 Development Board (×1)

Main controller and Wi-Fi web server.

MAX7219 Dot Matrix (4 Modules)

Displays the scrolling text message.

USB Cable (×1)

Used for programming and powering the ESP32.

Jumper Wires

Used for ESP32 to MAX7219 connections.

5V Power Supply (×1)

Provides suitable power to the setup.

Computer / Laptop / Mobile

Used to open the ESP32 web dashboard.

Arduino IDE Setup

  1. Open Arduino IDE.
  2. Go to Tools → Board → ESP32 Arduino → ESP32 Dev Module.
  3. Go to Tools → Port and select the ESP32 COM port.
  4. Open Sketch → Include Library → Manage Libraries.
  5. Install MD_Parola.
  6. Install MD_MAX72XX.
  7. Enter your Wi-Fi name and password in the program.
  8. Upload the program to the ESP32.
  9. Open Serial Monitor at 115200 baud.
The source instructions also mention connecting P0 to GND during upload, then removing the wire and pressing the reset button.

Working Principle

ESP32 Starts
↓
MAX7219 display initializes
↓
ESP32 connects to Wi-Fi
↓
Web server starts on ESP32
↓
User opens ESP32 IP address in browser
↓
User enters text in dashboard
↓
ESP32 sends message to MAX7219
↓
Message scrolls across dot matrix display
The dashboard allows messages up to 100 characters. It also includes a Clear Display button.

// =====================================================
// HOME
// =====================================================

void handleRoot()
{
  server.send(
    200,
    "text/html",
    webpage()
  );
}

// =====================================================
// SEND MESSAGE
// =====================================================

void handleSend()
{
  if (server.hasArg("text"))
  {
    String inputText = server.arg("text");

    inputText.trim();

    if (inputText.length() > 0)
    {
      if (inputText.length() > 100)
      {
        inputText = inputText.substring(0, 100);
      }

      inputText.toCharArray(
        message,
        sizeof(message)
      );

      matrix.displayClear();

      matrix.displayText(
        message,
        PA_LEFT,
        70,
        0,
        PA_SCROLL_LEFT,
        PA_SCROLL_LEFT
      );

      Serial.println();
      Serial.println("================================");
      Serial.println(" NEW MESSAGE");
      Serial.println("================================");
      Serial.print("Dashboard: ");
      Serial.println(message);
      Serial.println("MAX7219: Message started");
      Serial.println("================================");
      Serial.println();
    }
  }

  server.sendHeader(
    "Location",
    "/"
  );

  server.send(303);
}

// =====================================================
// CLEAR
// =====================================================

void handleClear()
{
  strcpy(message, "");

  matrix.displayClear();

  Serial.println();
  Serial.println("DISPLAY CLEARED");
  Serial.println();

  server.sendHeader(
    "Location",
    "/"
  );

  server.send(303);
}

// =====================================================
// SETUP
// =====================================================

void setup()
{
  Serial.begin(115200);

  delay(1000);

  Serial.println();
  Serial.println("================================");
  Serial.println(" ESP32 MAX7219CWG DOT MATRIX");
  Serial.println("================================");
  Serial.println();

  Serial.println("Starting MAX7219...");

  matrix.begin();

  matrix.setIntensity(5);

  matrix.displayClear();

  matrix.displayText(
    message,
    PA_LEFT,
    70,
    0,
    PA_SCROLL_LEFT,
    PA_SCROLL_LEFT
  );

  Serial.println("MAX7219 Started");

  WiFi.mode(WIFI_STA);

  Serial.println();
  Serial.print("Connecting to WiFi");

  WiFi.begin(
    ssid,
    password
  );

  while (
    WiFi.status() != WL_CONNECTED
  )
  {
    delay(500);
    Serial.print(".");
  }

  Serial.println();
  Serial.println();

  Serial.println("WiFi Connected!");

  Serial.print("ESP32 IP Address: ");
  Serial.println(
    WiFi.localIP()
  );

  server.on(
    "/",
    HTTP_GET,
    handleRoot
  );

  server.on(
    "/send",
    HTTP_GET,
    handleSend
  );

  server.on(
    "/clear",
    HTTP_GET,
    handleClear
  );

  server.begin();

  Serial.println();
  Serial.println("Web Server Started");
  Serial.println();

  Serial.println("Open this address:");

  Serial.print("http://");
  Serial.println(
    WiFi.localIP()
  );

  Serial.println();
  Serial.println("================================");
}

// =====================================================
// LOOP
// =====================================================

void loop()
{
  server.handleClient();

  if (matrix.displayAnimate())
  {
    matrix.displayReset();
  }
}

Expected Output

After the ESP32 connects to Wi-Fi, the Serial Monitor displays its local IP address. Opening that IP address in a browser shows the message dashboard.

Dashboard: Enter text and press SEND TO DOT MATRIX
Display: Message scrolls from left across the MAX7219 modules
Clear: CLEAR DISPLAY removes the current message
Serial Monitor: Shows Wi-Fi status, IP address and message activity

Result

The ESP Base Message Dashboard experiment was implemented using ESP32 and a 4-module MAX7219 dot matrix display. Text entered through the Wi-Fi web dashboard is sent to the ESP32 and displayed as a scrolling message on the dot matrix.
