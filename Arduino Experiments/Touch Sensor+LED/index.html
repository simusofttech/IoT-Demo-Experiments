Touch Sensor + LED

← Arduino Experiments Aim Components Connections Working Procedure Code Result

Aim

To interface a digital touch sensor with an Arduino UNO and control an LED according to the touch sensor output.

About the Experiment

The touch sensor provides a digital HIGH or LOW output. Arduino continuously reads the sensor signal using digitalRead().

When touch is detected, the LED turns ON and the Serial Monitor displays TOUCH DETECTED - LED ON. When there is no touch, the LED turns OFF and the Serial Monitor displays NO TOUCH - LED OFF.

Circuit Diagram

Connect the touch sensor output to D9 and the LED anode to D2 through a 220Ω or 330Ω resistor. Connect all grounds together.

Working Principle

↓

↓

Touch detected: LED ON
No touch: LED OFF
Serial Monitor: Displays current touch status

Procedure

  1. Connect the touch sensor VCC pin to Arduino 5V.
  2. Connect the touch sensor GND pin to Arduino GND.
  3. Connect the touch sensor OUT/SIG pin to D9.
  4. Connect the LED anode to D2 through a 220Ω or 330Ω resistor.
  5. Connect the LED cathode to GND.
  6. Connect Arduino UNO to the computer using USB.
  7. Open Arduino IDE.
  8. Enter the program given below.
  9. Select Arduino UNO from Tools → Board.
  10. Select the correct COM port.
  11. Verify and upload the program.
  12. Open Serial Monitor at 9600 baud.
  13. Touch the sensor and observe the LED and Serial Monitor.

Arduino Code

Touch_Sensor_LED.ino 
// ===============================
// Touch Sensor + LED Test
// ===============================

#define TOUCH_PIN 9
#define LED_PIN 2

void setup() {

  pinMode(TOUCH_PIN, INPUT);

  pinMode(LED_PIN, OUTPUT);

  digitalWrite(LED_PIN, LOW);

  Serial.begin(9600);

  Serial.println("================================");
  Serial.println("Touch Sensor Test Started");
  Serial.println("Touch the sensor...");
  Serial.println("================================");
}

void loop() {

  int touchState = digitalRead(TOUCH_PIN);

  if (touchState == HIGH) {

    // Touch detected
    digitalWrite(LED_PIN, HIGH);

    Serial.println("TOUCH DETECTED - LED ON");
  }

  else {

    // No touch
    digitalWrite(LED_PIN, LOW);

    Serial.println("NO TOUCH - LED OFF");
  }

  delay(300);
}

Expected Output

When the touch sensor is touched, the LED turns ON. When the sensor is not touched, the LED remains OFF.

Touch: TOUCH DETECTED - LED ON
No Touch: NO TOUCH - LED OFF
Serial Monitor Baud Rate: 9600

Result

The Touch Sensor + LED experiment was implemented using Arduino UNO, a digital touch sensor and an LED. The LED turns ON when touch is detected and turns OFF when no touch is detected.
